# My Portfolio Website

Welcome to my personal portfolio website! This site showcases my projects, skills, certifications, and contact information. It's designed to highlight my journey as a data analyst and software enthusiast.

## Features

- Responsive design for desktop and mobile
- Sections: About Me, Skills, Projects, Resume, Contact
- Clean and modern UI
- Deployed using Netlify

## Tech Stack

- *Frontend:* HTML, CSS, JavaScript (or React, if used)
- *Version Control:* Git & GitHub
- *Deployment:* Netlify
